Privacy policy

Perplexity Bulk Delete & Export, by KAM Studio. Last updated: 3 September 2026.

The short version

Your threads never leave your browser. There is no account, no server that stores anything about you, and no analytics. Only two kinds of request ever leave the extension: a licence check, if you enter a Pro key, and anonymous reads of our public settings, which tell it the site addresses to use and the text of the card shown on the free plan. Neither carries anything about you or your threads.

What the extension reads

When you press Scan, the extension reads the list of threads in your own Perplexity library: titles, dates, snippets and collection names. When you export, it also reads the messages in the threads you selected.

All of that stays in your browser's local extension storage. It is used to draw the table, to build your export file, and to remember where a delete run had got to if the browser restarts it. It is never uploaded anywhere.

You can erase all of it at any time by removing the extension, which deletes its storage with it.

How it reaches Perplexity

The extension does not sign in to Perplexity and never sees your password. It works through the Perplexity tab you already have open, using the session you are already signed in with, in the same way the site's own pages do. It stores no token and no cookie. Everything it does is something you could do yourself by clicking around the site.

What leaves your browser

Two kinds of request, and neither is about you.

1. Licence check. If you buy Pro and enter a licence key, that key is sent to Polar (polar.sh), our payment provider, so it can confirm the key is valid. It is re-checked about every three days. The request contains the licence key and a label naming your operating system, for example "BulkKit (Windows)", so you can recognise the device in your own Polar account. It contains nothing about your threads. If you never enter a key, this request never happens. Polar's own privacy policy covers what they do with it: https://polar.sh/legal/privacy

2. Public settings. The extension reads two small public tables from our Supabase project. One holds the site addresses it should use, which lets us fix the extension quickly if Perplexity changes something instead of waiting for a store review. The other holds the text of the card shown on the free plan. Both are anonymous reads, the same content for everybody, and they send nothing: no identifier, no usage data, not even a count. Both contain configuration values only, which are checked before use and never run as code.

These reads are switched off in the current release, so today the licence check is the only request that leaves the extension at all. They are described here because the extension is built to make them and a later release may switch them on.

Downloads

Export files are written by your browser to your own computer, to wherever your browser puts downloads. They do not pass through us.

Capture mode

There is a diagnostic mode, off by default, that records the shape of the requests the extension makes so we can correct it when a site changes: the address path, the method, the names of the headers, and a skeleton of each response where every value is replaced by its type. Header values, search terms, thread titles and message text are never recorded.

Even then, the result is saved as a file on your own computer. It is uploaded nowhere. It reaches us only if you choose to send it to us yourself.

Advertising

On the free plan the panel shows one small card for another KAM Studio product. It is plain text and a link, loaded from the public settings above. There is no ad network, no third-party script, no iframe and no tracking pixel, and nothing about you is used to choose it. You can switch it off in the panel's Plan tab, and Pro removes it.

Children

The extension is not directed at children and collects no data from anyone.

Changes

If this policy changes in a way that affects what leaves your browser, the change will be described in the extension's release notes, not only here.
