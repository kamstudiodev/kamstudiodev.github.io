PERPLEXITY BULK DELETE & EXPORT

By BulkKit

Perplexity keeps every search you have ever run. Perplexity Bulk Delete & Export is a Chrome extension that filters threads in your Perplexity library by keyword, date or collection, deletes them in bulk, and exports them to Markdown or JSON before deleting. Everything stays in your browser; no data leaves your device.

Get Pro ($4.99 one-time) Add to Chrome (Free)

Features

  • Targeted thread filtering: Filter threads by keyword, by date range, or by collection to locate exactly what you want to remove.
  • Export before deleting: Save selected threads to Markdown (one file per thread in a zip) or as a single JSON file. If an export fails, deletion halts immediately.
  • Controlled bulk deletion: Delete hundreds of threads in one pass with exact count confirmation, dry run verification, and mid-run cancellation.
  • Runs in your session: Works through the Perplexity tab you already have open. Never sees your password, stores no cookie or session token, and makes no calls to outside servers.
